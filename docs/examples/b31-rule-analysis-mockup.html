▸⛔ 不一致 (1)ERROR
R5 年龄校验 — 永不命中
条件自相矛盾：age == 20 且 age == 30，输入空间为空集，规则永远无法命中。
▸🔴 死规则 / 遮蔽 (1)WARN
R1 被 R3 完全覆盖
R3 的输入区间在所有共享维度上 ⊇ R1（amount>1000 ⊇ amount>5000、account_age_days<90 ⊇ <30），且 R3 优先级更高 → R1 的决策永远被 R3 抢先，永不胜出。
▸🟠 冲突 (1)WARN
R2 × R4 输入相交但决策对立
两规则输入区间相交（同 amount、account_age_days 范围），R2→BLOCK 而 R4→PASS，且优先级相等 → 同一笔交易结果不确定。
▸🟡 覆盖缺口 (1)WARN
Decision「ESCALATE」无规则产出
scene 绑定了 ESCALATE，但无任何规则路径 / 决策表行 / 决策树叶子产出它 → 绑定了却触达不到。
▸🔵 重叠 / 冗余 (2)INFO
R2 与 R3 部分重叠
输入区间相交但互不包含，决策相同（均 BLOCK）→ 可考虑合并，非错误。
决策表「额度风险矩阵」行2 × 行4 重叠
额度[1k,5k] × 评分[600,700) 两行输入相交（DMN overlap）；HIGHEST_PRIORITY 下由优先级裁决，提示而非错误。
▸⚪ 未分析 (1)SKIP
R6 复合条件 — 超出 v1 精确推理
含顶层 OR / MATCHES 正则，无法投影为可推理区间 → 跳过（灰显，非"无问题"，避免误判）。
