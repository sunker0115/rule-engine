# 决策效果回灌操作指南

决策效果页的精确率/召回率/触发率依赖于**回灌标签**——即把系统评估过的会话打上真实业务结果。

## 操作步骤

### 1. 进入决策效果页

菜单「决策效果」（`/effectiveness`），图标是折线图。

### 2. 查现有评估会话（获取 eventId）

打开 MySQL 查已有评估记录：

```sql
SELECT event_id, scene_code, status FROM evaluation_session LIMIT 5;
```

任取一个 `event_id` 准备回灌。

### 3. 点「回灌标签」按钮

页面顶部筛选栏最右边。打开 Modal 表单。

### 4. 填写回灌行

| 字段 | 必填 | 含义 | 示例 |
|---|---|---|---|
| eventId | ✅ | 评估会话的 event_id | `evt-mask-001` |
| outcomeLabel | ✅ | 真实结果标签 | `欺诈` 或 `正常` |
| outcomeValue | 否 | 数值标签 | `150.00` |
| labeledAt | ✅ | 真实结论确定时间 | 选日期 |
| source | 否 | 来源标识 | `人工核查` |
| note | 否 | 备注 | 随便填 |

- 一行填完后可以点虚线 `+` 按钮加行（批量回灌）。
- 填完点「确定」。

### 5. 验证是否落库

```sql
SELECT * FROM decision_outcome;
```

应看到刚填的记录。

### 6. 查效果报表

回到决策效果页：
- 选对应租户、场景、日期范围
- **bucket 切「按天」**（关键——不切按天折线图不显示）
- 点「查询」

表格显示 TP/FP/FN/TN/精确率/召回率/触发率。折线图按时间维度展示趋势（X 轴=日期桶，Y 轴=所选指标，不同 line=不同维度键）。
