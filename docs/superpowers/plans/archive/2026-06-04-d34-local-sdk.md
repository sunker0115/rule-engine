# D34 嵌入式 SDK 本地模式实现计划

> **Goal：** `RuleEngineClient` 支持无服务端的本地模式——调用方通过代码直接构造 `RuleVersionSnapshot` 注入本地索引，`build()` 时若无 `serverUrl` 则不启动 `SnapshotPoller`，`evaluate()` 路径完全不变。
>
> **适用场景：** 单测 / CI / 演示 / 完全离线部署。
>
> **决策依据：** D34（`00-decisions.md`）

---

## 影响范围

| 模块 | 文件 | 变更类型 |
|------|------|---------|
| `rule-kernel` | `RuleVersionSnapshot.java` | 新增内部 `Builder` 辅助类 |
| `rule-sdk` | `RuleEngineClient.java` | `Builder` 新增 `localSnapshot()` 方法；`build()` 判断是否启动 poller |
| `rule-sdk` | `RuleEngineClientTest.java` | 补本地模式测试 |

**不改的**：`SnapshotPoller`、`EvalEngine`、`SceneRuleIndex`、服务端任何模块。

## AST 节点构造速查

本地模式下调用方需要手动构造 AST，下面是完整的构造签名和示例。

### 节点类型

```java
// 叶子节点：conditionType 对应内置算子，metricCode 对应 event.providedMetrics 的 key
ConditionNode(String conditionType, String metricCode, String displayLabel,
              Map<String, Object> params, double weight)

// 逻辑节点
AndNode(List<AstNode> children, String displayLabel, Double weight)
OrNode(List<AstNode> children, String displayLabel, Double weight)
NotNode(AstNode child)
XorNode(List<AstNode> children, String displayLabel, Double weight)

// 评分卡根节点（kind=SCORECARD 时使用）
ScorecardRootNode(List<ConditionNode> conditions, double threshold)
```

### 内置算子（conditionType）与 params

| conditionType | params key | 含义 |
|---|---|---|
| `GT` / `GTE` | `threshold` | 数值大于 / 大于等于 |
| `LT` / `LTE` | `threshold` | 数值小于 / 小于等于 |
| `EQ` / `NEQ` | `value` | 等于 / 不等于 |
| `IN` / `NOT_IN` | `values`（List） | 包含于 / 不包含于集合 |
| `BETWEEN` / `NOT_BETWEEN` | `min`, `max` | 区间内 / 区间外 |
| `CONTAINS` / `NOT_CONTAINS` | `value` | 字符串包含 |
| `STARTS_WITH` / `ENDS_WITH` | `value` | 字符串前缀 / 后缀 |
| `MATCHES` | `pattern` | 正则匹配 |
| `DATE_BEFORE` / `DATE_AFTER` | `date`（ISO-8601 字符串） | 日期比较 |

### 完整规则构造示例

```java
// 规则：amount > 1000 AND country IN ["CN", "HK"]
AstNode ast = new AndNode(List.of(
        new ConditionNode("GT", "amount", null, Map.of("threshold", 1000), 0.0),
        new ConditionNode("IN", "country", null, Map.of("values", List.of("CN", "HK")), 0.0)
), null, null);

RuleVersionSnapshot snap = RuleVersionSnapshot.builder()
        .ruleVersionId(1L)
        .tenantId("t1")
        .sceneCode("fraud")
        .conditionAst(ast)
        .addTriggerEventType("TRANSACTION")
        .addDecisionBinding("BLOCK", 100)
        .build();

try (RuleEngineClient client = RuleEngineClient.builder()
        .localSnapshot(snap)
        .build()) {

    // 评估事件：amount=1500，country=CN → 命中规则
    RuleEvent event = new RuleEvent(
            "t1", "fraud", "TRANSACTION", "user-001",
            UUID.randomUUID().toString(), Instant.now(),
            Map.of(),
            Map.of("amount", 1500, "country", "CN")  // providedMetrics
    );
    EvalResult result = client.evaluate(event);
    // result.ruleHit() == true
    // result.finalDecision().decisionCode() == "BLOCK"
}
```

> `providedMetrics` 的 key 必须与 `ConditionNode.metricCode` 完全一致，引擎从这里取值对比 `params` 中的阈值。

### Step 3：为 `RuleVersionSnapshot` 添加 Builder

在 `RuleVersionSnapshot.java` 末尾（record 的 `}` 之前）添加静态 Builder 内部类：

```java
/** 链式构建器，用于本地模式代码定义规则快照。 */
public static Builder builder() { return new Builder(); }

public static final class Builder {
    private Long ruleVersionId;
    private String sceneCode;
    private String tenantId;
    private com.sstlfsj.rule.kernel.api.model.ast.AstNode conditionAst;
    private final java.util.List<PreGateConfig> preGates = new java.util.ArrayList<>();
    private final java.util.List<DecisionBinding> decisionBindings = new java.util.ArrayList<>();
    private final java.util.List<String> triggerEventTypes = new java.util.ArrayList<>();
    private String kind = "AST_BOOLEAN";

    /** 规则版本 ID（本地模式可传任意 Long）。 */
    public Builder ruleVersionId(Long v)  { this.ruleVersionId = v; return this; }
    /** 场景编码。 */
    public Builder sceneCode(String v)    { this.sceneCode = v; return this; }
    /** 租户 ID。 */
    public Builder tenantId(String v)     { this.tenantId = v; return this; }
    /** 条件 AST 根节点。 */
    public Builder conditionAst(com.sstlfsj.rule.kernel.api.model.ast.AstNode v) { this.conditionAst = v; return this; }
    /** 规则类型，默认 AST_BOOLEAN。 */
    public Builder kind(String v)         { this.kind = v; return this; }
    /** 追加一个监听的事件类型。 */
    public Builder addTriggerEventType(String v) { triggerEventTypes.add(v); return this; }
    /** 追加一个 Decision 绑定。 */
    public Builder addDecisionBinding(String decisionCode, int priority) {
        decisionBindings.add(new DecisionBinding(decisionCode, priority)); return this;
    }
    /** 追加一个 Pre-Gate 配置。 */
    public Builder addPreGate(String gateType, java.util.Map<String, Object> params) {
        preGates.add(new PreGateConfig(gateType, params)); return this;
    }

    /** 构建 RuleVersionSnapshot。 */
    public RuleVersionSnapshot build() {
        return new RuleVersionSnapshot(
                ruleVersionId, sceneCode, tenantId, conditionAst,
                java.util.List.copyOf(preGates),
                java.util.List.copyOf(decisionBindings),
                java.util.List.copyOf(triggerEventTypes),
                kind);
    }
}
```

## Task 2：`RuleEngineClient` 支持本地模式

// 恒真 AST 辅助方法：AndNode 三参构造 (children, displayLabel, weight)
private static AndNode alwaysTrue() {
    return new AndNode(List.of(), null, null);
}

// 单条件 AST：amount > 1000（通过 providedMetrics["amount"] 取值）
private static AndNode amountGt1000() {
    return new AndNode(List.of(
            new ConditionNode("GT", "amount", null, Map.of("threshold", 1000), 0.0)
    ), null, null);

@Test
void localMode_alwaysTrueRule_evaluatesHit() {
    // 空 AND 节点恒真，验证本地模式基本链路
    RuleVersionSnapshot snap = RuleVersionSnapshot.builder()
            .ruleVersionId(1L)
            .tenantId("t1")
            .sceneCode("fraud")
            .conditionAst(alwaysTrue())
            .addTriggerEventType("TRANSACTION")
            .addDecisionBinding("BLOCK", 100)
            .build();

    try (RuleEngineClient client = RuleEngineClient.builder()
            .localSnapshot(snap)
            .build()) {
        RuleEvent event = new RuleEvent("t1", "fraud", "TRANSACTION",
                "sub1", UUID.randomUUID().toString(),
                Instant.now(), Map.of(), Map.of());
        EvalResult result = client.evaluate(event);
        assertThat(result.ruleHit()).isTrue();
        assertThat(result.finalDecision().decisionCode()).isEqualTo("BLOCK");
    }
}

@Test
void localMode_conditionRule_hitWhenMetricMatches() {
    // 真实规则：amount > 1000；事件带 providedMetrics["amount"]=1500 → 命中
    RuleVersionSnapshot snap = RuleVersionSnapshot.builder()
            .ruleVersionId(2L)
            .tenantId("t1")
            .sceneCode("fraud")
            .conditionAst(amountGt1000())
            .addTriggerEventType("TRANSACTION")
            .addDecisionBinding("BLOCK", 100)
            .build();

    try (RuleEngineClient client = RuleEngineClient.builder()
            .localSnapshot(snap)
            .build()) {
        RuleEvent hit = new RuleEvent("t1", "fraud", "TRANSACTION",
                "sub1", UUID.randomUUID().toString(),
                Instant.now(), Map.of(), Map.of("amount", 1500));
        assertThat(client.evaluate(hit).ruleHit()).isTrue();

        RuleEvent miss = new RuleEvent("t1", "fraud", "TRANSACTION",
                "sub1", UUID.randomUUID().toString(),
                Instant.now(), Map.of(), Map.of("amount", 500));
        assertThat(client.evaluate(miss).ruleHit()).isFalse();
    }
}

### Step 3：修改 `RuleEngineClient`

**Builder 新增字段和方法：**

```java
private final List<RuleVersionSnapshot> localSnapshots = new ArrayList<>();
```

```java
/**
 * 添加本地规则快照（本地模式专用）。
 * 本地模式不需要 serverUrl，不启动 SnapshotPoller。
 * 不可与 serverUrl 混用。
 */
public Builder localSnapshot(RuleVersionSnapshot v) {
    localSnapshots.add(v); return this;
}
```

**`build()` 修改：**

```java
public RuleEngineClient build() {
    boolean hasServer = serverUrl != null && !serverUrl.isBlank();
    boolean hasLocal  = !localSnapshots.isEmpty();
    if (hasServer && hasLocal)
        throw new IllegalArgumentException("serverUrl 和 localSnapshot 不可同时配置");
    if (!hasServer && !hasLocal)
        throw new IllegalArgumentException("必须配置 serverUrl（HTTP 模式）或至少一个 localSnapshot（本地模式）");
    if (hasServer && (tenantId == null || tenantId.isBlank()))
        throw new IllegalArgumentException("HTTP 模式下 tenantId 必填");
    return new RuleEngineClient(this);
}
```

**构造器修改：** `RuleEngineClient(Builder b)` 中改 poller 构建逻辑：

```java
private RuleEngineClient(Builder b) {
    SceneRuleIndex index = new SceneRuleIndex();
    EvalContextAssembler assembler = new EvalContextAssembler(List.of(), List.of());
    RuleVersionExecutor executor = b.executor != null
            ? b.executor
            : new InterpretedExecutor(KernelEvaluators.defaults());
    this.evalEngine = new EvalEngine(index, assembler,
            b.preGates != null ? b.preGates : Map.of(),
            Map.of("AST_BOOLEAN", executor));

    // 本地模式：直接写入索引，不启动 SnapshotPoller
    if (!b.localSnapshots.isEmpty()) {
        for (RuleVersionSnapshot snap : b.localSnapshots) {
            List<String> eventTypes = snap.triggerEventTypes().isEmpty()
                    ? List.of("*") : snap.triggerEventTypes();
            for (String et : eventTypes) {
                // 同一 (tenantId, sceneCode, eventType) 可能有多条快照，追加而非覆盖
                List<RuleVersionSnapshot> existing = new ArrayList<>(
                        index.match(snap.tenantId(), snap.sceneCode(), et));
                if (!existing.contains(snap)) existing.add(snap);
                index.update(snap.tenantId(), snap.sceneCode(), et, existing);
            }
        }
        this.poller = null;
    } else {
        this.poller = new SnapshotPoller(b.serverUrl, b.tenantId, b.fetchMode,
                b.scenes, b.pollInterval, index);
        this.poller.start();
    }

    this.evalResultListener  = b.evalResultListener;
    this.evalSessionListener = b.evalSessionListener;
}
```

**`close()` 兼容 null poller：**

```java
@Override
public void close() {
    if (poller != null) poller.stop();
}
```

同时将 `poller` 字段改为可 null：

```java
private final SnapshotPoller poller; // null 表示本地模式
```
